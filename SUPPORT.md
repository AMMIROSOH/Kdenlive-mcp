# Support

This is a public-preview project maintained on a best-effort basis.

- Use GitHub Discussions for setup questions and workflow ideas when enabled.
- Use GitHub Issues for reproducible bugs and feature requests.
- Use private security advisories for vulnerabilities; see [SECURITY.md](SECURITY.md).

Before reporting a runtime problem, attach sanitized output from
`kdenlive-mcp --doctor`, the operating system, Node version, Kdenlive/MLT/FFmpeg
versions, and the smallest reproducible project. Never include bearer tokens,
private media, absolute paths you consider sensitive, or `.env` files.

Milestones 5 and 6 are planned work. Requests that depend on transcription,
semantic search, OTIO, or Kdenlive project round trips are feature requests, not
bugs in the current public preview.
